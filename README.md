# CurtainCall UI

یک وب اپلیکیشن مدرن برای رزرو بلیت تئاتر بساز با React و Tailwind CSS.

امکانات فاز اول:

- صفحه اصلی با هدر زیبا (لوگو TheaterReserve و منو)

- لیست نمایش‌های تئاتر به صورت کارت (عنوان، تاریخ، سالن، قیمت، تعداد صندلی باقی‌مانده)

- حداقل ۴ نمایش نمونه با داده‌های فارسی

- طراحی مدرن، تم تیره سینمایی، ریسپانسیو

- دکمه "مشاهده جزئیات و رزرو" روی هر کارت

هنوز نیازی به دیتابیس و فرم رزرو نیست. فقط صفحه اصلی و لیست نمایش‌ها.

از فونت فارسی پشتیبانی کن.
